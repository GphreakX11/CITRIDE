# Design
App owns selectedEntity, selectedCaseId, loaded case metadata and MapViewState. CommandWorkspace remains the sole case API/write owner; its existing fetch reports records to App via callback. Parent navigation carries explicit case/entity context without new API writes. Pure investigation helpers define linkage and selection, using captured records rather than current geography. Context bar lives above command/expert content. CommandReadouts passes controlled map props. TexasInfrastructureMap uses parent state and a pure relationship helper to render summary and direct supplier/dependent views; secondary context disclosure remains available. Preserve source/model/auth/deployment state with existing metadata-only release evidence scripts.
