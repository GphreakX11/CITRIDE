# Design

Replace only COP rendering in CommandReadouts with TexasInfrastructureMap. Pure texasGraph derives real edges and stable display positions from Bootstrap. Real state-boundary SVG backs an explicitly illustrative topology overlay; near-zero synthetic coordinates are not interpreted as Texas coordinates.

Default shows infrastructure and actual dependency/structural links. Selection inserts direct abstract/cyber neighbors, dims unrelated records, highlights incident edges and opens an in-place inspector. Structural/spatial edges differ from amber directed service dependencies. Neighbor rows traverse records; raw evidence remains reachable in expert tools.

SVG keyboard nodes have equivalent native entity selection. Phone layout stacks inspector below map. Zoom/reset/pan affect only view state. Search/filter changes reconcile selection. Missing/dangling references are excluded without invented edges. Boundary attribution is local in texasOutline.ts and disclosure.

Ownership: parent component/CSS/integration/outline/specs; child helper and Node tests. No backend/schema/deployment modifications.
